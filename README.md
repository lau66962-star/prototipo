# 🌫️ Prototipo — "¿Qué significa valer?"

> Un juego pixel art indie narrativo: un protagonista invisible en un mundo gris,
> y el gesto cotidiano que siembra la pregunta más importante del juego.

## 🗺️ Mapa del proyecto

| Ruta | Qué es |
|---|---|
| `GDD.md` | Documento de diseño del juego (visión, mecánicas, decisiones) |
| `presentacion.md` | Sinopsis + pilares — para mostrar a profesores y amigos |
| `documentacion/decisiones.md` | Decisiones tomadas y abiertas (se actualiza siempre) |
| `documentacion/arquitectura-poo.md` | POO aplicado al juego + estructura en Godot |
| `documentacion/git-cheatsheet.txt` | La chuleta de comandos de Git |
| `assets/README.md` | Packs de recursos, licencias y qué falta conseguir |
| `escenas/` | El guion del juego (escenas escritas) |
| `game/` | El proyecto Godot (código, escenas, recursos) |
